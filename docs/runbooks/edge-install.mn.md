# Заавар: Касс edge-ийг шинэ компьютерт суулгах, шинэчлэх (Windows, Ubuntu)

Энэ бол `edge-install.md`-ийн монгол хувилбар (ADR-0067, ADR-0136).

Касс edge нь гурван хэсэгтэй, бүгд Docker дотор ажилладаг:

- `edge-db`: edge-ийн өгөгдлийн сан;
- `edge`: edge сервер;
- `kiosk`: кассын хуудас.

Тиймээс компьютерт зөвхөн **Docker** болон **git** хэрэгтэй, Node эсвэл pnpm суулгах шаардлагагүй.

Суулгах скрипт `deploy/edge/.env` файлыг шинэ дотоод нууц утгуудтай үүсгээд edge-ийг асаана. Үүний дараа edge-ийг кассын хуудаснаас нэг удаагийн кодоор төв системтэй холбоно. Токен эсвэл PIN түлхүүрийг хэн ч гараар хуулахгүй.

> Жинхэнэ төв сервер ажиллаж эхлэх хүртэл (S5, ADR-0026) төв систем нь эзэмшигчийн компьютер дээрх dev сервер байна. Тэр нь `start.bat`-аар асдаг бөгөөд хаяг нь `http://192.168.1.215:5173` эсвэл API-ийн `:3300`. Энэ бол туршилтын тохиргоо. Скрипт `EBARIMT_PROVIDER=fake` тавьдаг тул эзэмшигч зөвшөөрөх хүртэл татварын албанд юу ч илгээгдэхгүй.

## Ерөнхий дараалал

1. Төв систем дээр «Супермаркет → Пос» хуудсанд дэлгүүрийн edge сервер бүртгэлтэй байх ёстой. Бүртгэлгүй бол нэг удаа үүсгэнэ:
   - код (жишээ нь `MRN1`);
   - нэр;
   - STORE агуулах.
2. Шинэ компьютер дээр Docker болон git суулгаад repo-г татна. Дараа нь суулгах скриптийг ажиллуулна (доорх «Windows» эсвэл «Ubuntu» хэсэг).
3. `http://<шинэ компьютерийн IP>:7400`-ийг нээгээд «Төв системтэй холбох» дэлгэцэд гурван зүйл оруулна:
   - төв системийн хаяг;
   - edge-ийн код;
   - «Холбох код».
4. Касс бүрийг өөрийн «Холбох код»-оор холбоно. Кассчид PIN кодоороо нэвтэрнэ.

## Өөр компьютер дээр ажиллаж байгаа edge-ийг шилжүүлэхийн өмнө

1. Бүх кассын нээлттэй ээлжийг хаана.
2. «Супермаркет → Пос» хуудсанд хуучин edge-ийн илгээгээгүй гүйлгээ 0 болсныг шалгана. Ингэснээр бүх борлуулалт төв рүү очсон гэсэн үг.
3. Хуучин edge-ийг зогсооно: эзэмшигчийн компьютер дээр `pnpm edge:down`, бусад компьютер дээр `docker compose … down`.

Нэг edge серверт хоёр edge зэрэг бүү ажиллуул. Шинэ edge холбогдох үед шинэ токен авдаг тул хуучин edge тэр даруй ажиллахаа болино.

Өдрийн эхэнд, анхны борлуулалтаас өмнө шилжүүлнэ. Шинэ edge өөрийн өгөгдлийн сангаа шинээр эхлүүлдэг тул өдрийн баримтын дугаар дахин эхэлнэ.

## Windows (10 эсвэл 11)

1. Хоёр програм суулгана:
   - **Docker Desktop**: https://www.docker.com/products/docker-desktop/, эсвэл `winget install -e --id Docker.DockerDesktop`;
   - **Git**: `winget install -e --id Git.Git`.

   Компьютерийг дахин асаахыг шаардвал асаана. Docker Desktop-ийг нэг удаа нээгээд ажиллаж эхлэхийг хүлээнэ. Docker Desktop → Settings → General хэсэгт «Start Docker Desktop when you sign in»-ийг чагтална. Ингэснээр компьютер дахин асахад edge өөрөө асна.
2. Repo-г зайгүй нэртэй хавтас руу татна, жишээ нь `C:\bto`:

   ```text
   git clone https://github.com/ez4puljin/Bto.git C:\bto
   ```

3. `C:\bto\deploy\edge\setup-windows.bat` файлыг давхар дарна. Эхний удаа image бүтээх тул 10–20 минут болно (ойролцоогоор 4 GB санах ой, 10 GB зай хэрэгтэй). Төгсгөлд нь `Бэлэн. Кассын хуудас: http://<хаяг>:7400` гэж гарна.
4. Бусад кассын компьютерээс нэвтрэх боломжтой болгохын тулд нэг удаа файл дээр баруун товч дараад «Run as administrator»-аар ажиллуулна. Энэ нь Windows firewall дээр кассын портыг нээнэ.
5. Router дээр компьютерт тогтмол IP хаяг өгнө (DHCP reservation). Кассууд тэр хаягаар холбогдоно.

## Ubuntu (22.04 эсвэл 24.04)

1. git суулгаад repo-г татна:

   ```bash
   sudo apt update && sudo apt install -y git
   git clone https://github.com/ez4puljin/Bto.git ~/bto
   ```

2. Суулгах скриптийг ажиллуулна:

   ```bash
   bash ~/bto/deploy/edge/setup.sh
   ```

   Скрипт дараах ажлуудыг хийнэ:
   - Docker байхгүй бол суулгана (sudo нууц үг асууна);
   - тохиргооны файлыг бичнэ;
   - edge-ийг бүтээж асаана (эхний удаа 10–20 минут);
   - `ufw` асаалттай бол кассын портыг нээнэ.
3. Router дээр компьютерт тогтмол IP хаяг өгнө (DHCP reservation). Компьютер асахад Docker өөрөө асах бөгөөд edge-ийн хэсгүүд мөн өөрсдөө дахин асна (`restart: unless-stopped`).

## Edge-ийг төв системтэй холбох (хоёр системд адилхан)

1. Төв систем дээр «Супермаркет → Пос» → edge серверийн мөр → **«Холбох код»** (гинжин холбоосын дүрс) товчийг дарна. Гарч ирэх цонхонд гурван зүйл харагдана:
   - код (`ABCD-EF23`, 15 минут хүчинтэй, нэг л удаа харагдана);
   - төв системийн хаяг;
   - edge-ийн код.
2. Дэлгүүрийн аль нэг компьютерийн хөтөч дээр `http://<edge компьютерийн IP>:7400`-ийг нээнэ. Шинэ edge **«Төв системтэй холбох»** дэлгэц харуулна:
   - «Төв системийн хаяг»: цонхонд гарсан хаяг. Хэрэв `localhost` гэж гарсан бол оронд нь төв компьютерийн дотоод IP-г бичнэ. Жишээ нь `http://192.168.1.215:5173` (dev вэб, `/api`-г дамжуулдаг) эсвэл `http://192.168.1.215:3300` (dev API).
   - «Edge серверийн код»: жишээ нь `MRN1`.
   - «Холбох код»: 1-р алхмын код. Зураасгүй эсвэл жижиг үсгээр бичсэн ч болно.
3. «Холбох» товчийг дарна. Edge токен болон PIN түлхүүрээ төвөөс өөрөө авч, өөрийн өгөгдлийн санд хадгална. Дараа нь дэлгүүрийн мэдээллийг шууд татна. Үүний дараа кассыг холбох дэлгэц гарна.
4. Пос бүрийг нээнэ:
   - кассчны компьютерийн Chrome дээр `http://<edge компьютерийн IP>:7400` гэж нээхэд «Пос сонгох» жагсаалт гарна. Тухайн компьютерийн посыг дарахад `…:7400/K1` руу шилжинэ. Эсвэл `http://<edge компьютерийн IP>:7400/K1` гэж шууд нээнэ. Энэ хаяг «Супермаркет → Пос» хуудасны «Хаяг» баганад байна. Код асуухгүйгээр шууд К1 пос болно (ADR-0138);
   - кассчин PIN-ээрээ нэвтэрнэ;
   - хаягийн ард `/K1` байхгүй бол хуучнаараа посын 6 оронтой «Холбох код» асууна.

   Посын shortcut болон хэвлэгчийн тохиргоо: `pos-till-printing.md`.

Таван удаа буруу код оруулбал тухайн код хүчингүй болно, шинээр авна. «POS_PIN_PEPPER тохируулаагүй» гэсэн алдаа гарвал төв сервер production горимд ажиллаж байгаа ч `POS_PIN_PEPPER` тохируулаагүй байна. Эхлээд төв дээр тохируулна (ADR-0136 #4).

## Ubuntu дээрх edge-ийг шинэчлэх (update)

Шинэ хувилбар GitHub-ийн `main` дээр орсны дараа edge-ийг ингэж шинэчилнэ. `.env` болон edge-ийн өгөгдөл хадгалагдана: холболт, илгээгээгүй борлуулалт, кассуудын холболт бүгд хэвээр үлдэнэ.

1. **Хэзээ хийх вэ:** ажлын бус цагт, эсвэл худалдан авагчгүй үед хийнэ. Шинэчлэлийн үеэр edge болон кассын хуудас 1–3 минут унтарна. Ээлж хаах шаардлагагүй. Нээлттэй ээлж, сагс, илгээгээгүй гүйлгээ edge-ийн өгөгдлийн санд хадгалагдсан хэвээр байна.
2. Ubuntu компьютер дээр terminal нээгээд шинэ кодыг татна:

   ```bash
   cd ~/bto && git pull
   ```

   «Already up to date» гэж гарвал шинэчлэх юм алга, энд зогсоно.
3. Edge-ийг шинэ кодоор дахин бүтээж асаана:

   ```bash
   bash ~/bto/deploy/edge/setup.sh
   ```

   Скрипт байгаа `.env`-ийг хэвээр үлдээнэ («… байгаа тул хэвээр үлдээлээ» гэж гарна). Image-ийг дахин бүтээнэ (ихэвчлэн 3–10 минут). Edge асахдаа өөрийн өгөгдлийн сангийн шинэчлэлийг (migration) өөрөө хийнэ.
4. Шалгах:

   ```bash
   cd ~/bto && docker compose -f deploy/edge/docker-compose.edge.yml --env-file deploy/edge/.env ps
   ```

   Гурван хэсэг (`edge-db`, `edge`, `kiosk`) бүгд `healthy` эсвэл `running` байх ёстой. Үүний дараа:
   - кассын хуудсыг refresh хийж, кассчин нэвтэрч чадаж байгаа эсэхийг шалгана;
   - төв дээр «Супермаркет → Пос» хуудсанд edge-ийн «сүүлд холбогдсон» цаг шинэчлэгдэж байгааг харна.
5. Асуудал гарвал логийг харна:

   ```bash
   cd ~/bto && docker compose -f deploy/edge/docker-compose.edge.yml --env-file deploy/edge/.env logs --tail 200 edge
   ```

6. Хуучин image-ууд дискийг дүүргэхээс сэргийлж хааяа цэвэрлэнэ:

   ```bash
   docker image prune -f
   ```

   Энэ нь ашиглагдаагүй image-ийг л устгана, edge-ийн өгөгдөлд хүрэхгүй.

Анхааруулга:
- `git pull` «local changes» гэсэн алдаа гаргавал repo доторх файлыг гараар өөрчилсөн байна. `.env` git-д ордоггүй тул энэ алдааг үүсгэхгүй. Юуг өөрчилснөө `git status`-аар хараад, админд хэлнэ.
- Шинэчлэлийг буцаахаас өмнө админтай зөвлөнө. Шинэ хувилбар edge-ийн өгөгдлийн санг шинэчилсэн бол хуучин хувилбар түүн дээр ажиллахгүй байж магадгүй.

## Windows дээрх edge-ийг шинэчлэх

1. `C:\bto` хавтсанд Git Bash эсвэл PowerShell нээгээд `git pull` хийнэ.
2. `deploy\edge\setup-windows.bat`-ыг дахин давхар дарна.
3. Шалгах, лог харах нь Ubuntu-тай адил (дээрх 4–5-р алхам).

## Бусад

- **Лог харах** (repo хавтаснаас): `docker compose -f deploy/edge/docker-compose.edge.yml --env-file deploy/edge/.env logs -f --tail 100 edge`.
- **Зогсоох:** `docker compose -f deploy/edge/docker-compose.edge.yml --env-file deploy/edge/.env down`. `-v` хэзээ ч бүү нэм: энэ нь edge-ийн өгөгдлийн санг илгээгээгүй борлуулалт, холболттой нь хамт устгана.
- **«Шинэ токен»-ийг гараар гаргавал:** кодоор холбогдсон edge ажиллахаа болино. Кассын хуудас (касс холбогдоогүй үед) дахин «Төв системтэй холбох» дэлгэц гаргана. Шинэ кодоор ижил edge сервер рүү холбоно.
- **Төв систем унтарсан үед:** кассууд зарсаар байна. Борлуулалтууд edge дээр хадгалагдаж байгаад төв дахин асахад илгээгдэнэ.
- **Edge төв системтэй нэг компьютер дээр бол:** төвийн хаяг `http://host.docker.internal:3300` байна.
- **Жинхэнэ төв сервер рүү шилжих:** холбогдсон edge өөр төв рүү шилждэггүй. Жинхэнэ төв ажиллаж эхлэхэд дараах дарааллаар шилжинэ:
  1. ээлжүүдийг хаана;
  2. илгээгээгүй гүйлгээ 0 болохыг хүлээнэ;
  3. туршилтын edge-ийг өгөгдөлтэй нь устгана (`… down -v`);
  4. скриптийг дахин ажиллуулна;
  5. жинхэнэ төвөөс авсан кодоор холбоно.

  Эсвэл хуучин аргаар `deploy/edge/.env`-д `CENTRAL_API_URL`, `EDGE_NODE_TOKEN`, `POS_PIN_PEPPER` гурвыг бичнэ. Энэ нь кассын хуудаснаас хийсэн холболтоос давуу эрхтэй.
