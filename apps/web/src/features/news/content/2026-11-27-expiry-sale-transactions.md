# Хугацааны хямдралтай гүйлгээний бүртгэл

Касс болон борлуулалтын хугацааны хямдралтай барааны борлуулалт, буцаалт анхны зөвшөөрөлтэйгээ холбогдон бүртгэгдэнэ.
Кассанд дууссан гүйлгээний хямдралын тооцоонд зөрчил гарвал гүйлгээг бүртгэж, ажилтанд шинэ төлбөр ногдуулахгүйгээр шалгах тэмдэглэл хадгална.
Хугацааны хямдрал, цалингийн холбогдох эрхтэй ажилтнууд энэ бүртгэлийг ашиглана. Удирдах дэлгэцүүд дараагийн шинэчлэлтээр нэмэгдэнэ.
