# Банкны хуулга: дэвтэрт бичсэн мөрийг засах, түүх, сарын хөл дүн

«Санхүү → Банкны хуулга» хэсэгт:

- Дэвтэрт бичсэн мөрийг шууд засаад «Гүйлгээ засах» дарна. Зөвхөн засагдсан гүйлгээ шинэчлэгдэнэ, бусад нь хэвээрээ.
- Өдрийн хуулга дээрх «Түүх» товчоор хэн, хэзээ, юуг зассаныг харна.
- «Шимтгэл» → «Сараар»: нэг сарын шимтгэл нэг Excel файл болно (жишээ нь `Шимтгэл_2026-11.xlsx`). «Нэгтгэсэн экспорт»-д шимтгэл ордоггүй тул хоёуланг нь татна.
- Календарын доорх «Сарын хөл дүн»: данс бүрийн орлого, зарлага, цэвэр дүн, шимтгэл.
- Шимтгэл, settlement мөрийн харилцагчийн кодыг «Тохиргоо» хэсэгт тус тусад нь бичнэ.
