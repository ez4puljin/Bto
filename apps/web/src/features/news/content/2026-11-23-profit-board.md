# Ашгийн самбар

«Тайлан → Ашгийн самбар» шинээр нэмэгдлээ. Сар, улирал, жилээр борлуулалт, өртөг, нийт ашгийг өмнөх үе болон өнгөрсөн жилийн мөн үетэй харьцуулж харна.

- Урсгал зардал, бусад орлого, татварыг санхүүгийн бичилтээс уншиж үйл ажиллагааны ашиг, цэвэр ашгийг харуулна.
- Ашгийг нийлүүлэгч, барааны ангилал, байршил, ХТ, салбараар задалж, мөр бүрийн ард ямар бараа байгааг нээж үзнэ.
- «Өртөг, ашиг харах» эрхтэй хүнд л харагдана.
