# НӨАТ хасуулах

Харилцагч НӨАТ-ын баримт авахгүй, оронд нь өрөө бууруулахыг хүсвэл тухайн борлуулалт дээр «НӨАТ хасуулах» товчийг дарна. Харилцагчийн авлага тэр борлуулалтын дүнгийн 2 хувиар буурна.

- Цэс: «Санхүү → Харилцагчийн тооцоо» → харилцагч → «Борлуулалт».
- Зөвхөн «НӨАТ хасуулах» эрхтэй хүн хийнэ.

Дэлгэрэнгүй: [НӨАТ хасуулах](/guide/finance/noat-hasuulah)
