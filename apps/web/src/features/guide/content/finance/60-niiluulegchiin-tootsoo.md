# Нийлүүлэгчийн тооцоо: өглөг, баталсан нягтлан, сегмент

Нийлүүлэгч бүрт хэдэн төгрөг өгөхийг, хэзээ сүүлд өглөг үүссэнийг, орлого бүрийн үнийг аль нягтлан баталсныг нэг дороос харна. Цэс: «Санхүү → Нийлүүлэгчийн тооцоо».

## Жагсаалт ба шүүлтүүр

1. Жагсаалтад код, нэр, ангилал, сегмент, тооцоо (өгөх дүн), сүүлийн өглөгийн огноо харагдана. Хамгийн их өглөгтэй нь дээрээ.
2. Нийлүүлэгчийг нэр, кодоор хайна. «Бүх ангилал»-аас нийлүүлэгчийн ангиллаар, «Бүх сегмент»-ээс сегментээр шүүнэ.
3. Мөр дээр дарахад тухайн нийлүүлэгчийн өглөгийн дэвтэр нээгдэнэ.

## Өглөг хэрхэн үүсэж, буурдаг вэ

1. Нярав орлогыг батлахад бараа үлдэгдэлд орно, гэхдээ өглөг хараахан үүсэхгүй.
2. Нягтлан «Орлого» руу орж падааны үнийг шалгаад «Үнэ батлах» дарахад өглөг үүснэ. Орлогын хуудсанд «Баталсан нягтлан» гэж тэр нягтлангийн нэр, огноо харагдана.
3. Нийлүүлэгчийн дэвтэрт орлого бүрийн баримтын ард «Баталсан нягтлан» баганад батласан нягтлангийн нэр гарна.
4. Нийлүүлэгчид төлсөн төлбөрийг «Журнал» дээр гар бичилтээр (Дебит: Дансны өглөг, нийлүүлэгчийг сонгоно) эсвэл банкны хуулгаар оруулахад өглөг шууд буурна. Тусдаа «тулгалт» хийх алхам байхгүй.
5. Үнэ нь батлагдаагүй орлогыг харах бол нийлүүлэгчийн хуудасны «Үнэ батлаагүй орлого» товчийг дарна. Тэр нийлүүлэгчийн үнэ шалгах орлогууд жагсаалтаар гарна.

## Нийлүүлэгчийн сегмент үүсгэх

1. «Сегмент үүсгэх» товч (эсвэл «Сегмент» цэс, «Нийлүүлэгч» таб) дээр дарна. Энэ эрх админд байна.
2. Нэр өгөөд нөхцөл сонгоно: «Нийлүүлэгч» нөхцөлөөр нийлүүлэгчдийг нэг нэгээр нь сонгоно, «Ангилал» нөхцөлөөр нэг ангиллын бүх нийлүүлэгчийг авна. Хэд хэдэн нөхцөлийг «Бүгд биелэх» эсвэл «Аль нэг нь биелэх»-ээр холбоно.
3. Хадгалсны дараа сегментийн нэр тооцооны жагсаалтын «Сегмент» баганад гарч, «Бүх сегмент» шүүлтүүрт нэмэгдэнэ.

## Асуудал гарвал

- Өглөг нь 0 боловч бараа ирсэн: орлогын үнэ батлагдаагүй байна. «Үнэ батлаагүй орлого»-оос нээж нягтлан батална.
- Сегмент сонгоход нийлүүлэгч гарахгүй: тэр нийлүүлэгч өглөггүй, эсвэл сегментийн нөхцөлд таарахгүй байна. Сегментийн хуудсанд хэдэн нийлүүлэгч таарч байгааг шалгана.
