# Худалдан авалтын e-Barimt-ыг API-аар татах

«Санхүү → Ebarimt» хуудас сарын худалдан авалтын e-Barimt баримтуудыг татварын албаны e-Barimt системээс шууд татаж чадна. Ингэснээр сар бүр Excel файл гараар татаж оруулах шаардлагагүй болно. Холболтыг нэг удаа бөглөхөд Bto шөнө бүр өөрөө татна, «Одоо татах» товчоор хүссэн үедээ татна.

Excel файл оруулах арга хэвээр ажиллана. Сүүлд орсон нь хүчинтэй байна: Excel оруулбал API-аар татсаныг солино, дараагийн татлага өөр баримт авчирвал Excel-ийг солино.

## Нэг удаа: холболт бөглөх

Үүнийг «Ebarimt»-ийн тохиргоо өөрчлөх эрхтэй ажилтан (админ, нягтлан) хийнэ.

1. «Санхүү → Ebarimt» хуудсыг нээгээд баруун дээд талын «Тохиргоо» товчийг дарна.
2. «e-Barimt холболт» табыг сонгоно.
3. «Орчин»-оос сонгоно:
   - «Туршилтын»: татварын албаны туршилтын систем. Бодит түлхүүр ирэх хүртэл холболтыг шалгахад хэрэглэнэ. Эндээс ирэх баримт жинхэнэ биш.
   - «Бодит»: жинхэнэ худалдан авалтын баримт.
4. «Нэвтрэх нэр», «Нууц үг», «API түлхүүр (X-API-KEY)»-ийг Татварын ерөнхий газраас албан бичгээр ирүүлсэн хариунаас яг хуулж бичнэ.
5. «Байгууллагын регистр»: компанийн бүртгэлд регистр байвал өөрөө бөглөгдөнө. Зөв эсэхийг шалгана.
6. Шөнө бүр өөрөө татуулах бол «Шөнө бүр автоматаар татах»-ыг чагтална.
7. «Хадгалах» дарна.

Хадгалсны дараа нууц үг, API түлхүүр дахин харагдахгүй, талбарт «хадгалсан» гэж бичигдэнэ. Солих бол шинээр бичээд хадгална. «Орчин»-ыг солибол хадгалсан нууц үг, түлхүүр арилна: шинэ орчных нь утгыг дахин бичнэ.

> Нууц үг, түлхүүрээ хэнд ч бүү дамжуул. Чат, имэйлээр бүү явуул. Зөвхөн энэ цонхонд өөрөө бичнэ.

## Шөнийн автомат татлага

Асаалттай бол Bto шөнийн 01:30-д энэ сарын өчигдөр хүртэлх бүх баримтыг татна. Сарын 1-нээс 10-ны хооронд өмнөх сарынхыг ч дахин татна, учир нь нийлүүлэгчид баримтаа хожуу оруулдаг.

Баримт өөрчлөгдөөгүй бол юу ч нэмэгдэхгүй, түүхэнд мөр гарахгүй. Шинэ баримт ирсэн эсвэл өөрчлөгдсөн бол тухайн сарын файл шинэчлэгдэж, нийлүүлэгч бүрийн e-Barimt дүн болон түүх файл оруулсантай адил шинэчлэгдэнэ.

> Бодит орчинд татварын алба зөвхөн шөнийн 01:00–07:00 цагт хариу өгнө. Тиймээс өдөр «Одоо татах» дарвал «татварын алба татгалзсан» гэж гарч болно. Шөнийн татлагыг хүлээнэ үү.

## Одоо татах

1. Хуудасны «Сараар» горимд хэрэгтэй сараа сонгоно.
2. Сарын мөрөнд «Одоо татах» товч харагдана (холболт бүрэн бөглөгдсөн, засах эрхтэй бол). Дарна.
3. Доор нь мэдэгдэл гарна: хэдэн баримт татсан, эсвэл «өөрчлөлтгүй».

Сарын мөрөнд «Эх сурвалж: API» эсвэл «Эх сурвалж: Excel» гэж тухайн сарын файл хаанаас ирснийг харуулна. Хулганаа дээр нь аваачвал сүүлийн татлагын төлөв харагдана.

## Төлөв юу гэсэн үг вэ

Тохиргооны «e-Barimt холболт» табын дээд талд сүүлийн татлагын төлөв бичигдэнэ:

- «Сүүлд татсан: 2026.11.21 01:30, 245 баримт» — амжилттай. Тоо нь тэр удаад татсан нийт баримт.
- «Татаж чадсангүй: …» — татаж чадаагүй. Шалтгаан нь ард бичигдэнэ. Сарын мөрөнд ч улаан «Татаж чадсангүй» тэмдэг гарна.

«{n} баримтын ТТД далд» гэсэн шар тэмдэг: татварын алба зарим баримтын борлуулагчийн ТТД-г одоор далдалж ирүүлсэн (жишээ нь `57***85`). Ийм баримтыг нийлүүлэгчтэй ТТД-аар тулгах боломжгүй тул «Бүртгэлгүй» жагсаалтад үлдэнэ. Тэндээс ДДТД-аар нь харж, зөв нийлүүлэгчид холбоно.

## Татаж чадсангүй бол

| Юу харагдаж байна | Юу хийх |
|---|---|
| «холболтын тохиргоо дутуу» | Тохиргоо → «e-Barimt холболт»-д нэвтрэх нэр, нууц үг, API түлхүүр, регистр бүгд бөглөгдсөн эсэхийг шалгаад хадгална. |
| «хадгалсан нууц үг эсвэл түлхүүрийг нээж чадсангүй» | Серверийн нууцлах түлхүүр солигдсон байна. Нууц үг, API түлхүүрээ дахин бичиж хадгална. Давтагдвал админд хэлнэ. |
| «нэвтрэх нэр эсвэл нууц үг буруу» | Албан бичгийн хариунаас нэвтрэх нэр, нууц үгээ дахин хуулж бичнэ. «Орчин» зөв эсэхийг шалгана: туршилтын нэр бодит орчинд ажиллахгүй. |
| «татварын алба татгалзсан («…»)» | Хаалтанд татварын албаны өөрийн тайлбар байна. Бодит орчинд өдөр татвал ийм гарна: шөнийн татлагыг хүлээнэ. API түлхүүр буруу бол түлхүүрээ шалгана. Ойлгомжгүй бол тайлбарыг нь татварын албанд хэлж лавлана. |
| «татварын албаны сервер хариу өгсөнгүй» | Интернэт эсвэл татварын албаны систем түр тасарсан. Хэсэг хүлээгээд «Одоо татах» дахин дарна. Шөнийн татлага дараагийн шөнө өөрөө дахин оролдоно. |
| «татварын албаны хариуг уншиж чадсангүй» | Татварын алба сервисээ өөрчилсөн байж болно. Админд хэлнэ. Тэр хооронд сарын Excel файлыг гараар оруулж ажиллана. |
| «энэ сар эхлээгүй байна» | Ирээдүйн сар сонгосон байна. Өнөөдрийн эсвэл өмнөх сараа сонгоно. |

Татаж чадаагүй үед өмнө нь байсан сарын файл хэвээр үлдэнэ, юу ч устахгүй.
