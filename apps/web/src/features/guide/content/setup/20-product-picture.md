# Барааны зургийн тохиргоо: фон хасах түлхүүр, лого

«AI ашиглах»-аар бараа нэмэхэд барааны зургийн фоныг хасаж, цагаан дэвсгэр дээр компанийн логотой болгоно. Үүнд фон хасах үйлчилгээний (remove.bg) түлхүүр, логоны файл хэрэгтэй.

## Тохируулах

1. «Систем → Тохиргоо» хуудсыг нээж «AI» табыг сонгоно.
2. «Барааны зураг» хэсэгт «remove.bg API түлхүүр»-ээ бичнэ.
3. «Түлхүүр шалгах» дарна.
4. «Компанийн лого» дээр логоны зургаа оруулна. Лого зургийн зүүн дээд буланд зурагдана.

## Тохируулаагүй үед

Бараа нэмэх ажил хэвийн явна. Зөвхөн барааны зураг дарсан хэвээрээ, фонтойгоо орно.

> remove.bg нь төлбөртэй үйлчилгээ: зураг бүрд кредит зарцуулна. Үлдэгдлээ тэдний хуудаснаас харна.
