# USB scanner-ийн туслах програм суулгах

USB-ээр оффисын компьютерт залгасан printer-scanner-ийг (жишээ нь HP LaserJet Pro MFP M125a) Bto-гийн «Падаан scan хийх» товчоор ажиллуулахын тулд тэр компьютер дээр нэг удаа суулгана.

## Суулгахаас өмнө

- Windows 10 эсвэл 11-тэй компьютер байх.
- Scanner асаалттай, USB-ээр залгаатай байх.
- Windows-ийн «Scan» эсвэл «Windows Fax and Scan» програмаар scan хийж чаддаг байх. Чадахгүй бол эхлээд scanner-ийн драйверийг суулгана.
- Scanner-тай ажилладаг хүн өөрийн нэрээр Windows-д нэвтэрсэн байх.

## Суулгах

1. Start цэсэн дээр `PowerShell` гэж бичнэ.
2. «Windows PowerShell» дээр хулганы баруун товчоор дараад «Run as administrator» сонгоно. «Yes» дарна.
3. Доорх мөрийг хуулж тавиад Enter дарна:

```
irm https://raw.githubusercontent.com/ez4puljin/Bto/main/tools/scan-bridge/install.ps1 | iex
```

4. Хагас минутын дараа ногоон `INSTALLED.` гэсэн мөр, scanner-ийн нэр гарна. Доор нь цэнхэрээр хаяг бичигдэнэ, жишээ нь `http://192.168.1.23:8765`. Энэ хаягийг тэмдэглэж авна.

## Bto дээр холбох

1. Bto-д админ эрхээр нэвтэрч «Агуулах → Орлого → Падаан унших» хуудсыг нээнэ.
2. «Scanner тохируулах → Scanner нэмэх» дарна.
3. Нэр (жишээ нь «Оффис HP»), дээрх хаягийг бичнэ.
4. «Шалгах» дарна. «Scanner олдлоо» гэж гарвал «Хадгалах» дарна.

Үүний дараа «Падаан унших» хуудсанд «Падаан scan хийх» товч гарна. [Падааныг scanner-аар оруулах](/guide/inventory/scan-note) зааврыг үзнэ.

## Анхаарах зүйлс

- Scan хийх үед тэр компьютер асаалттай, хүн нь Windows-д нэвтэрсэн байх ёстой.
- Компьютерийн сүлжээний хаяг өөрчлөгдвөл Bto холбогдож чадахгүй. Router дээр тэр компьютерт тогтмол хаяг оноолгоно. Өөрчлөгдсөн бол суулгах мөрийг дахин ажиллуулж, шинэ хаягийг Bto-д засна.
- Туслах програм зөвхөн Bto серверийн хүсэлтэд хариулна.
- Нэг удаад нэг хуудас scan хийнэ.

## Ажиллахгүй бол

| Юу харагдаж байна | Юу хийх |
|---|---|
| Улаан `NOT INSTALLED` | PowerShell-ийг «Run as administrator»-оор нээгээгүй. Дахин нээж эхэлнэ. |
| Шар `no scanner found` | Scanner унтраалттай эсвэл кабель салсан. Асаагаад Windows-ийн «Scan» програмаар шалгана. Дахин суулгах шаардлагагүй. |
| Bto дээр «Scanner-тай холбогдож чадсангүй» | Компьютер унтарсан, хүн нь нэвтрээгүй, эсвэл хаяг өөрчлөгдсөн. |
| Bto дээр «Scanner алдаа буцаалаа» | Scanner унтарсан эсвэл тагийг нь буруу хаасан. `C:\ProgramData\BtoScan\bridge.log` файлд шалтгаан бичигдэнэ. |
