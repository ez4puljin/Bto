# Падааныг scanner-аар оруулах

Scanner холбогдсон бол падааныг файл болгож хадгалалгүйгээр «Падаан унших» хуудаснаас шууд scan хийнэ.

## Scan хийх

1. «Агуулах → Орлого → Падаан унших» хуудсыг нээнэ.
2. Падааны нэг хуудсыг scanner-ийн шилэн дээр доош харуулж тавина.
3. «Падаан scan хийх» дарна. 20–30 секундэд хуудас дэлгэцэнд гарна.
4. Дараагийн хуудсыг тавиад «Хуудас нэмэх» дарна.
5. Бүх хуудас орсны дараа «Унших (OCR)» дарна.

Үүнээс хойш ердийнхөөрөө шалгаж ноорог хадгална. [Падаанаас орлого бөглөх](/guide/inventory/receipt-notes) зааврыг үзнэ.

> «Хуудас хаана байгаа» сонголтыг «Шилэн дээр» хэвээр үлдээнэ. «Дээд тэжээгчид» нь олон хуудсыг өөрөө татдаг тэжээгчтэй scanner-т л зориулагдсан.

## «Падаан scan хийх» товч харагдахгүй бол

Scanner бүртгээгүй байна. Админ хоёр зүйл хийнэ:

1. Scanner USB-ээр компьютерт залгаатай бол тэр компьютерт туслах програм суулгана. [USB scanner-ийн туслах програм суулгах](/guide/setup/scan-bridge) зааврыг үзнэ.
2. «Падаан унших» хуудасны «Scanner тохируулах» дээр scanner-ийн хаягийг оруулна.

Scanner байхгүй үед зураг эсвэл PDF файлаар «Файл нэмэх» дарж оруулна.

## Ажиллахгүй бол

| Юу харагдаж байна | Юу хийх |
|---|---|
| «Scanner-тай холбогдож чадсангүй» | Scanner-ийн компьютер асаалттай, хүн нь Windows-д нэвтэрсэн эсэхийг шалгана. |
| «Scanner хариу өгсөнгүй» | Scanner өөрөө асаалттай эсэхийг шалгана. |
| «Scanner алдаа буцаалаа» | Scanner-ийн кабель, тагийг шалгаад дахин дарна. |
| «Тэжээгчид цаас алга» | «Шилэн дээр»-ийг сонгоод дахин дарна. |
