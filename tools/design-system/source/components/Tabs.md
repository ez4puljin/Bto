Sections of one record or one form, with a `primary` rule under the open tab.

**When:** a long item form in a side `Sheet`, with one footer for every tab so one «Хадгалах» saves all. A record panel keeps its open section in the URL (`?tab=`).

**Rules:** a section that edits stays mounted (`forceMount`) and takes the `hidden` attribute while another is open, so edits survive. For a few views of a list use `SegmentedControl`. Name the list with `aria-label`.
