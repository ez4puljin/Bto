Bto's mark on the web: a `primary` rounded square with the first letter of the app's name in white.

Use it beside the name in the top bar, the drawer, the sign-in pages and the till. It is live text in Inter, drawn with `mark-topbar` and `radius-lg`, or `mark-large` and `radius-xl`; it is not an image. The phone apps carry the drawn mark from `assets/Logos` instead.

**Consumer provides:** a size (`className` in the source) and the name beside it. Mark it `aria-hidden`: the name says it.

**Don't** recolour it, add a second letter on the web, or redraw the phone's mark as text.
