A pick-one filter pill you can type into, for a choice too long to scan.

**When:** a filter bar with many options (suppliers, categories). Matching uses the shared search keys of `@tugeel/shared/text`, by label and `keys`; ↑ ↓ move, Enter picks, Escape closes.

**Props:** `aria-label`, `value` (empty means "all"), `options` (`{ value, label, hint?, keys? }`), `emptyLabel`, `onChange`, `className`.
