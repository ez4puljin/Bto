A tick for choosing rows or several values, `primary` when on.

**When:** the first column of a list with bulk actions, and checkbox lists in filter dialogs. On/off settings use `Switch`, never a lone checkbox.

**Consumer provides:** a name such as «{name} сонгох». In a row, put it inside a `<label>` that fills its cell, so a click beside the box ticks it rather than opening the record. «Бүгдийг сонгох» is indeterminate between none and all.
