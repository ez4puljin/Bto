The name of a field: 13 px medium in `foreground`, tied to its control with `htmlFor`.

**When:** usually through `FormRow` or `FormField`, not by hand. Tie a `Switch` with `htmlFor` too. Screen readers and tests find the field by this name.

**Don't** repeat the label inside a select: start it with a plain «Агуулах сонгоно уу». A disabled peer dims the label to 50%.
