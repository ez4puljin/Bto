A status pill: dark text of a hue on a tint of the same hue, always a word, never colour alone.

**When:** beside a record's title in `meta`, in a list's status column, on a board card. Follow the status table in the brand book: blue is in progress, green done or active, grey draft, orange needs attention, red refused or broken, outline cancelled.

**Consumer provides:** one or two Mongolian words; an optional icon sized `icon-size-xs`.

**Don't** use a badge as a button, or make a new colour for a new status. A square `PaymentLabel` on a board card stays apart on purpose: it never reads as a status.
