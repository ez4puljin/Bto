# Icons

A representative set of 40 from `lucide-react` 1.53.0 (ISC), the only icon system in Bto: the controls the kit uses, then the shell's and the modules'. In code, import the same icon from `lucide-react`; take any other from the same package.

These files carry `input` (`#8e8e93`) as their single ink, because an `<img>` cannot inherit a colour and this grey reads on light and dark grounds. In a screen the icon is inline and follows the text with `currentColor`. Stroke 2, drawn on a 24 grid, shown at `icon-size` 16 px in a default button, a row or a menu item.
