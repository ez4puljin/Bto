# Bto-гийн принтерийн туслах програм: суулгах заавар

Компьютерт USB-ээр залгасан 80 мм-ийн баримтын (дулааны) принтер дээр ажилчид утаснаасаа үнийн шошго
хэвлэхийн тулд тэр компьютер дээр нэг удаа суулгана. Програм Bto сервероос хэвлэх шошгыг асууж аваад
принтер рүү шууд илгээнэ. Компьютер дээр порт нээхгүй.

## Суулгахаас өмнө

- Windows 10 эсвэл 11-тэй компьютер байх.
- Принтер асаалттай, USB-ээр залгаатай, драйвер нь суусан байх (Windows-ийн «Printers & scanners»-д
  харагддаг байх).
- Принтертэй ажилладаг хүн өөрийн нэрээр Windows-д нэвтэрсэн байх.

## Bto дээр принтер нэмэх

1. Bto-д админ эрхээр нэвтэрч «Систем → Принтер» руу орно.
2. «Принтер нэмэх» дарна. Нэр (жишээ нь «Заалны принтер»), төрөл «Компьютерт залгасан» сонгоод
   «Хадгалах» дарна.
3. Цонхонд суулгах мөр гарна. «Хуулах» дарж авна. Энэ мөр зөвхөн нэг удаа харагдана: хаавал
   «Шинэ түлхүүр» дарж дахин авна.

## Компьютер дээр суулгах

1. Start цэсэн дээр `PowerShell` гэж бичнэ.
2. «Windows PowerShell» дээр хулганы баруун товчоор дараад «Run as administrator» сонгоно. «Yes» дарна.
3. Bto-гоос хуулсан мөрийг тавиад Enter дарна.
4. Компьютерийн принтерүүдийн жагсаалт дугаартайгаа гарна. Шошгоны принтерийн дугаарыг бичээд Enter
   дарна.
5. Хагас минутын дараа ногоон `INSTALLED.` гэж гарна.
6. Bto-гийн «Систем → Принтер» хуудсанд принтер «Холбогдсон» болно. «Туршилтын шошго» дарахад нэг
   шошго гарч ирвэл бэлэн.

## Асуудал гарвал

- **`NOT INSTALLED: this window is not an administrator window.`** — PowerShell-ийг «Run as
  administrator»-оор нээгээгүй байна. Хаагаад дахин нээнэ.
- **`Windows shows no printer`** — принтерийн драйвер суугаагүй. Эхлээд принтерийг Windows-д суулгана.
- **`INSTALLED, BUT: ... refused the key`** — түлхүүр буруу эсвэл хуучирсан. Bto дээр «Шинэ түлхүүр»
  дарж шинэ мөр авч дахин суулгана.
- **`INSTALLED, BUT: ... does not answer`** — компьютер Bto сервертэй холбогдохгүй байна. Сүлжээгээ
  шалгана (`http://192.168.1.250` хаяг хөтөч дээр нээгдэх ёстой).
- **Принтер «Холбогдоогүй» хэвээр** — компьютер унтарсан эсвэл тэр хүн Windows-оос гарсан байна.
  Нэвтрэхэд програм өөрөө асна.
- **Шошго хэвлэгдэхгүй, «Принтер холбогдоогүй байна» гэж гарна** — компьютер 2 минутын дотор
  шошгыг аваагүй. Компьютер асаалттай, хүн нэвтэрсэн эсэхийг шалгана.
- Тэмдэглэл (log): `C:\ProgramData\BtoPrint\bridge.log`.

## Устгах

Администратор PowerShell дээр:

```powershell
irm https://raw.githubusercontent.com/ez4puljin/Bto/main/tools/print-bridge/uninstall.ps1 | iex
```

Дараа нь Bto дээр принтерийг «Идэвхгүй болгох» дарна.
