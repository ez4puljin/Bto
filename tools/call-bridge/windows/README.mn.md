# Утасны AI захиалга: компьютер дээрх програм

Хоёр янзаар ажиллана:

- **Туршилт (2-р шат, `local`)**: утас хэрэггүй, компьютерийн чихэвчээр AI-тай ярьж үзнэ (A–D хэсэг).
- **Жинхэнэ дуудлага (3-р шат, `bluetooth`)**: оффисын утас руу хэн нэгэн залгахад «Bto
  дуудлага» апп компьютерээс асууж, ажлын бус цагт AI хариулна. Дуу утас ба компьютерийн хооронд
  Bluetooth-ээр (Windows Phone Link) явна; нэмэлт төхөөрөмж худалдаж авах шаардлагагүй (E хэсэг).

Яриа бүхэлдээ Bto-д бичигдэнэ («Борлуулалт → Утасны дуудлага»). Програм дуудлага бүрийн хариулах
хурдыг хэмжинэ. Ярианы дуу хаана ч хадгалагдахгүй.

## A. Нэг удаа: ElevenLabs ба серверийн тохиргоо

1. **ElevenLabs бүртгэл.** elevenlabs.io дээр компанийн имэйлээр бүртгүүлж, «Agents» ашиглах
   багц (төлбөртэй) сонгоно.
2. **API түлхүүр.** ElevenLabs → Developers → API Keys → «Create key». Эрхүүдээс «ElevenAgents»
   (Conversational AI) уншиж, бичих эрхтэй байна. Түлхүүрийг хуулна. Түлхүүрийг хэзээ ч чат,
   баримт бичигт буулгахгүй.
3. **Түлхүүрийг серверт хийх.** Сервер дээр (`nvme-server`):

   ```sh
   cd ~/bto
   nano deploy/store/.env
   ```

   `ELEVENLABS_API_KEY=` мөрийн ард түлхүүрээ тавина. Хадгалах: Ctrl+O, Enter, Ctrl+X.
4. **AI агентыг ElevenLabs руу илгээх** (сервер дээр, `~/bto` хавтсанд):

   ```sh
   export PATH="$HOME/.local/opt/node/bin:$PATH"
   set -a; . deploy/store/.env; set +a; node tools/call-bridge/agent/push.mjs
   ```

   Анх удаа хийхэд төгсгөлд нь `ELEVENLABS_AGENT_ID=agent_...` гэсэн мөр гарна. Тэр мөрийг
   `deploy/store/.env` дахь `ELEVENLABS_AGENT_ID=` мөрийн оронд тавина (3-р алхам шиг).
   Дараа нь агентын тохиргоо (заавар, хэрэгсэл) өөрчлөгдөх бүрт яг энэ командыг дахин ажиллуулна:
   тэр үед шинэ агент үүсгэхгүй, байгаагаа шинэчилнэ.
5. **Серверт мэдэгдэх.** `cd ~/bto && bash deploy/store/setup.sh`. Хэдэн минутын дараа Bto шинэ
   түлхүүрээр ажиллана.
6. **Шугам.** Bto → «Систем → Утасны AI шугам»: шугам нэмж, ажлын цагаа тохируулж, шугамыг асаана (идэвхжүүлнэ).
   Туршихын тулд ажлын цагийг одоогийн цагаас гадуур (эсвэл тухайн өдөр хоосон) байлгана: ажлын
   цагт AI хариулахгүй, «ажилтан хариулна» гэнэ. Борлуулалтын тохиргооны сувгуудад «Утас (AI)»-ийн
   шат сонгогдсон байна. Шугамын хуудсанд түлхүүр гарна: нэг л удаа харагдана, хадгалж авна.
   Компьютер дээр ажиллуулах мөр (B хэсэг):

   ```powershell
   [Net.ServicePointManager]::SecurityProtocol='Tls12'; & ([scriptblock]::Create((irm https://raw.githubusercontent.com/ez4puljin/Bto/main/tools/call-bridge/windows/install.ps1))) -Server 'http://192.168.1.250' -Key 'bpl_...'
   ```

   `bpl_...`-ийн оронд шугамын түлхүүрийг тавина.

## B. Компьютер дээр суулгах

Windows 10 эсвэл 11 (64 бит). Админ эрх хэрэггүй.

1. Start цэсэнд `PowerShell` гэж бичээд «Windows PowerShell»-ийг энгийнээр нээнэ.
2. A хэсгийн 6-р алхмын мөрийг (түлхүүртэйгээ) тавиад Enter дарна. Програм эхлээд Python болон хэрэгтэй сангуудыг
   татна (интернэт хэрэгтэй, хэдэн минут).
3. **Чихэвч сонгох.** Дууны төхөөрөмжүүд дугаартайгаа гарна (`mic` = микрофон, `speaker` =
   чихэвч/чанга яригч). Чихэвчийнхээ микрофоны дугаарыг, дараа нь чихэвчийнхээ дугаарыг бичнэ.
   Enter дарвал Windows-ийн үндсэн төхөөрөмж сонгогдоно. **Чихэвч заавал**: чанга яригчаар
   ярьвал AI өөрийнхөө дууг сонсоод өөрөө өөртэйгөө ярина.
4. Ногоон `INSTALLED.` гарвал бэлэн. Ширээний дэлгэцэнд «Bto AI call» товчлол гарна.

Төхөөрөмжөө дараа нь солих бол «Bto AI call» → `5`. Цэс: `1`/`2` туршилтын дуудлага (чихэвчээр),
`3` хэмжилт, `4` Bto шалгах, `5` төхөөрөмж, `6` утас холбох, `7` Bluetooth/Phone Link/VB-Cable
шалгах, `8` дуудлагын төхөөрөмж олох, `9` цуурай хэмжих.

## C. Туршилтын дуудлага

1. «Bto AI call»-ийг нээнэ. Цэс гарна.
2. `1` — **дэлгүүрийн дугаараас**: Bto-д бүртгэлтэй дэлгүүрийн утасны дугаарыг бичнэ (жишээ нь
   `99112233`). AI тэр дэлгүүр залгаж байгаа мэт нэрээр нь мэндэлнэ, захиалга авна.
   `2` — **нууцалсан дугаараас**: танигдаагүй залгагч: бараа байгаа эсэхийг л хэлнэ, захиалга
   авахгүй, «ажилтан эргэж залгана» гэж бүртгэнэ.
3. AI мэндэлнэ: «Сайн байна уу, Оргил бөөний төвийн захиалгын AI туслах байна. Яриа бичигдэж
   байгаа. Юугаар туслах вэ?». Энгийнээр ярина: «Кока кола байна уу?», «Хоёр хайрцаг авъя»,
   «Хүргэлтээр», «Тийм», «Миний өчигдрийн захиалга хаана явна?».
4. Дэлгэц дээр ярианы үг гарахгүй (нууцлал): зөвхөн хэн хэдэн секундэд ярьсан, ямар хэрэгсэл
   хэдэн мс-д хариулсан гарна.
5. **Дуусгах**: AI баяртай гээд өөрөө тасална. Өөрөө таслах бол **Ctrl+C**. 40 секунд чимээгүй
   байвал эсвэл 10 минут болбол AI эелдгээр дуусгана.
6. Дууссаны дараа дүн гарна: дуудлагын дугаар, үр дүн (ORDERED = захиалга авсан, CALLBACK =
   эргэж залгах, …), захиалгын дугаар, хариулах хурд, хайлтын тоо. Bto-гийн «Борлуулалт →
   Утасны дуудлага» хуудсанд тэр дуудлагыг нээвэл яриа бүхэлдээ байна; захиалга «Ноорог»
   болж самбарт орсон байна.

## D. Хэмжилт унших

«Bto AI call» → `3` (эсвэл `python -m btobridge report --last 50`):

- **хариулах хугацаа: медиан** — залгагч ярьж дуусахаас AI хариулж эхлэх хүртэл, мс. Зорилт:
  1500 мс-ээс бага. **p90** — 10 хариултын 9 нь үүнээс хурдан.
- **мэндчилгээ** — дуудлага хүлээж авснаас AI мэндэлж эхлэх хүртэл. Зорилт: 1500 мс-ээс бага.
- **хайлт / олдоогүй** — AI хэдэн удаа бараа хайсан, хэд нь юу ч олоогүй. Олдоогүй хайлтууд
  Bto-гийн «Утасны дуудлага» хуудсанд «Олдоогүй хайлтууд»-д нэрээрээ гарна: тэдгээрийг
  барааны нэр/хайлтын үгэнд нэмбэл дараа нь олдоно.

Тоонууд `%LOCALAPPDATA%\BtoCall\metrics.csv` файлд хадгалагдана (зөвхөн тоо, ярианы үг биш).

**Хурдан LLM-ийг сайн LLM-тэй харьцуулах.** Анх Claude Haiku 4.5 (хурдан). Сервер дээр:

```sh
set -a; . deploy/store/.env; set +a; node tools/call-bridge/agent/push.mjs --llm claude-sonnet-4-6
```

Ижил туршилтын ярианууд хийгээд хэмжилтийг харьцуулна; буцаах бол `--llm`-гүйгээр дахин
ажиллуулна.

## E. Жинхэнэ дуудлага: утас + Bluetooth (Phone Link)

Ингэж ажиллана: залгагч → оффисын утас (Samsung, «Bto дуудлага» апп) → апп Wi-Fi-аар
компьютерээс «авах уу?» гэж асууна → компьютер Bto-гоос асууна (ажлын цаг бол «үгүй», утас
ердийнхөөрөө дуугарч ажилтан авна) → «тийм» бол утас дуудлагыг авч, дуу нь Bluetooth-ээр
компьютер дээр гарна → компьютер тэр дууг AI руу, AI-гийн хариуг утас руу дамжуулна.

Компьютер, утас хоёр **нэг Wi-Fi/сүлжээнд** байна (192.168.1.x). Утас 3 секундэд хариу авахгүй
бол ердийнхөөрөө дуугарна: компьютер унтарсан, интернэт тасарсан ч дуудлага алдагдахгүй.

### E1. VB-Cable суулгах (нэг удаа, админ эрхтэй)

VB-Cable бол үнэгүй «виртуал кабель»: AI-гийн дууг Phone Link-ийн микрофон руу оруулна.

1. Хөтөч дээр **https://vb-audio.com/Cable/** (зөвхөн энэ албан ёсны хуудас) нээж,
   «Download» → `VBCABLE_Driver_Pack...zip` татна.
2. Zip-ийг задлаад `VBCABLE_Setup_x64.exe` дээр баруун товч → **Run as administrator** →
   **Install Driver**.
3. Компьютерээ **дахин асаана**.

### E2. Phone Link ба утас (нэг удаа)

1. Компьютер дээр **Phone Link** (Microsoft Store-оос «Phone Link») нээж, Samsung утсаа холбоно
   (QR код). Утсан дээр «Link to Windows»-д зөвшөөрнө.
2. Phone Link → **Calls** (Дуудлага) хэсгийг тохируулна: утас компьютертэй Bluetooth-ээр
   холбогдож, «дуудлага хийх, авах» зөвшөөрлийг утсан дээр өгнө.
3. Шалгах: өөр утаснаас оффисын утас руу залгаад Phone Link дээр авна: залгагчийн дуу компьютерийн
   чихэвчинд сонсогдох ёстой.

### E3. Windows-ийн дууны тохиргоо (нэг удаа)

`Win + R` дараад `mmsys.cpl` гэж бичээд Enter. «Sound» цонх гарна.

1. **Recording** (Бичлэг) хуудас: **«CABLE Output (VB-Audio Virtual Cable)»** дээр баруун товч →
   **Set as Default Communication Device**, дахин баруун товч → **Set as Default Device**.
   Энэ нь Phone Link-ийн микрофон болно: AI-гийн дуу залгагч руу эндээс явна.
   Мөн «CABLE Output» → **Properties → Listen** хуудсанд «Listen to this device» **сонгоогүй** байна.
2. **Playback** (Тоглуулах) хуудас: дуудлагын дуу гарах төхөөрөмж дээр (одоо HyperX чихэвч:
   **«Headset Earphone (HyperX Cloud Alpha S Chat)»**) баруун товч → **Set as Default
   Communication Device**. **«CABLE Input»-ийг хэзээ ч Default болгохгүй.**
3. Phone Link-ийн дуудлагын цонх эсвэл Settings-д микрофон/чанга яригч сонгох газар байвал:
   микрофон = **«CABLE Output»**, чанга яригч = дээрх дуудлагын төхөөрөмж.
4. Анхаар: үүний дараа бусад програмын (Zoom, Discord) «үндсэн микрофон» нь CABLE Output болно.
   Тэдгээр програмд HyperX микрофоноо гараар сонгоно.

Дуудлагын дуу HyperX чихэвчинд гарч байгаа тул туршилтын үед та дуудлагыг сонсож чадна (хяналтад
тохиромжтой). Дараа нь өөр төхөөрөмж рүү шилжүүлэх бол: `mmsys.cpl` → Playback → тэр төхөөрөмжийг
(жишээ нь «Speakers (Realtek)») **Default Communication Device** болгоод «Bto AI call» → `8`-аар
дахин олуулна. Дуудлагын төхөөрөмжийг Windows дээр **Mute хийхгүй** (програм сонсохгүй болж
магадгүй); дууг чанга яригчийн товчоор багасгана.

### E4. Програмыг Bluetooth горимд суулгах

Энгийн PowerShell дээр (A хэсгийн 6-р алхмын мөрийн төгсгөлд ` -Mode bluetooth` нэмнэ):

```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; & ([scriptblock]::Create((irm https://raw.githubusercontent.com/ez4puljin/Bto/main/tools/call-bridge/windows/install.ps1))) -Server 'http://192.168.1.250' -Key 'bpl_...' -Mode bluetooth
```

1. Програм эхлээд шалгана: **Bluetooth**, **Phone Link**, Bluetooth-ээр холбогдсон **утас**,
   **VB-Cable**. `ДУТУУ` гэсэн мөр гарвал тэр мөрөнд бичсэнийг хийгээд дахин ажиллуулна.
2. **Дуудлагын төхөөрөмж** асууна. Хамгийн амар нь `D`: өөр утаснаас оффисын утас руу залгаж,
   Phone Link дээр аваад, залгасан утсаараа ярьсаар байх зуураа `D` дарна. Програм дуу аль
   төхөөрөмж дээр гарч байгааг өөрөө олно. Эсвэл жагсаалтаас дугаарыг (HyperX Chat бол `19`) бичнэ.
3. **Firewall.** Утас компьютер руу 8766 портоор холбогдоно. Шар өнгөөр
   `firewall: ... ONE command` гарвал: Start → `PowerShell` → баруун товч → **Run as
   administrator** → дараах мөрийг тавиад Enter (нэг л удаа):

   ```powershell
   New-NetFirewallRule -DisplayName 'Bto call bridge (phone link)' -Direction Inbound -Protocol TCP -LocalPort 8766 -RemoteAddress LocalSubnet -Action Allow -Profile Any
   ```

   Windows «Python-д сүлжээ зөвшөөрөх үү?» гэж асуувал **Allow** дарна. Хэрэв андуурч **Cancel**
   дарсан бол админ PowerShell дээр:

   ```powershell
   Get-NetFirewallApplicationFilter | Where-Object { $_.Program -like '*\BtoCall\python\*' } | Get-NetFirewallRule | Where-Object { $_.Action -eq 'Block' } | Remove-NetFirewallRule
   ```

### E5. Утсыг компьютертэй холбох («Bto дуудлага» апп)

1. Утсан дээр «Bto дуудлага» аппыг суулгаж, **үндсэн утасны апп** (default phone app) болгоно.
2. Компьютер дээр «Bto AI call» → `6` **утас холбох**. 6 оронтой код, компьютерийн хаяг
   (жишээ нь `192.168.1.35`) гарна. Код 10 минут хүчинтэй.
3. Апп → **«Компьютер холбох»**: хаяг, кодыг оруулна. Компьютер дээр `Холбогдлоо` гарна.
4. Апп дээр **«AI хариулах»**-ыг асаана.
5. Цэсний дээд хэсэгт `утас: ХОЛБОГДСОН` гарч байх ёстой.

Утасны хаяг (IP) өөрчлөгдвөл компьютер түүнийг танихгүй (аюулгүй байдлын үүднээс зөвхөн холбосон
хаягийг зөвшөөрнө). Тиймээс утсанд **тогтмол IP** өгнө: роутерийн тохиргоонд утасны хаягийг
«DHCP reservation»-оор бэхлэх, эсвэл утасны Wi-Fi → тухайн сүлжээ → IP settings → Static. Хаяг
өөрчлөгдсөн бол `6`-аар дахин холбоход хангалттай.

### E6. Цуурай, дууны түвшин хэмжих (нэг удаа, дараа нь шаардлагатай үед)

«Bto AI call» → `9`. Өөр утаснаас оффисын утас руу залгаж, Phone Link дээр аваад Enter. Програм
2 секунд «дүүү» дуу гаргана (залгасан утсанд сонсогдоно), дараа нь залгасан утсаараа 5 секунд
ярина. Дүн энгийн үгээр гарна:

- «Цуурай байхгүй / бага» — хэвийн.
- «AI-гийн дуу ... чанга буцаж ирж байна» — програм `echo_gate`-г асаах эсэхийг асууна: `т`.
  Тэгвэл AI ярьж байхад залгагчийн дууг чимээгүй болгоно (сул тал: залгагч AI-г яриан дунд нь
  таслах боломжгүй).
- «Залгагчийн дуу сул / хэт чанга / тасарч байна» — Windows дээр дуудлагын төхөөрөмжийн дууг
  тохируулна.

### E7. Туршилтын жинхэнэ дуудлага

1. Bto → «Систем → Утасны AI шугам»: одоо **ажлын бус цаг** байх ёстой (туршихын тулд ажлын цагийг
   түр өөрчилж болно), шугам асаалттай.
2. **Өөр утаснаас** оффисын утас руу залгана. 3 секунд дотор утас өөрөө авч, AI мэндэлнэ.
3. Ярьж үзээд AI баяртай гэж тасална. «Bto AI call» → `3`-т **дуугарснаас авах хүртэл** (3000
   мс-ээс бага) ба **холбогдсоноос мэндлэх хүртэл** (зорилт 1500 мс-ээс бага) хугацаа гарна.
4. Ажлын цагт залгавал утас ердийнхөөрөө дуугарна (AI авахгүй).

### Кабель (өөр арга, хийгээгүй)

Утсыг USB дууны карттай утсаар холбох арга (ADR-0232 #13 A) нэмэлт эд анги (USB дууны карт, TRRS
салаалагч, конденсатор, резистор) шаарддаг тул одоогоор хийгээгүй. Bluetooth арга сайн ажиллахгүй
бол дахин ярилцана.

## Асуудал гарвал

- **`NOT INSTALLED: the key does not look like ...`** — түлхүүр буруу хуулагдсан. Bto-гоос дахин
  хуулна (шаардлагатай бол «Түлхүүр шинэчлэх»).
- **`pip could not install`** — интернэт тасарсан. Мөрийг дахин ажиллуулна.
- **`Bto түлхүүрийг хүлээж авсангүй`** — түлхүүр хуучирсан: шугамын хуудсанд «Түлхүүр шинэчлэх»
  дараад дахин суулгана.
- **`Bto хариу өгөхгүй байна`** — компьютер Bto сервертэй холбогдохгүй: `http://192.168.1.250`
  хөтөч дээр нээгдэх ёстой.
- **`config.json алга`** гарвал суулгах мөрийг дахин ажиллуулна.
- **`Bto «хариулахгүй» гэв: ажлын цаг`** — шугамын ажлын цаг одоо: туршихын тулд ажлын цагаа
  түр өөрчилнө. **`шугам унтраалттай`** — шугамыг асаана. **`AI бэлэн биш`** — A хэсгийн 3–5-р
  алхам дутуу. **`утасны AI захиалгын шат тохируулаагүй`** — борлуулалтын тохиргоонд шат сонгоно.
- **`ElevenLabs хариу өгсөнгүй`** — интернэт, эсвэл ElevenLabs-ийн багц/түлхүүр.
- **AI сонсохгүй байна / өөрөө өөртэйгөө ярина** — `5`-аар зөв микрофон, чихэвч сонгоно; Windows
  → Sound settings-д микрофоны түвшинг шалгана; чанга яригч биш чихэвч хэрэглэнэ.
- **`арын програм: АЖИЛЛАХГҮЙ`** — компьютерээ дахин асаана, эсвэл суулгах мөрийг дахин ажиллуулна.
- **`утас: холбогдоогүй`** — утас Wi-Fi-д байгаа эсэх, апп нээлттэй эсэх, firewall-ийн мөр (E4-3)
  хийгдсэн эсэх, утасны IP өөрчлөгдсөн эсэхийг (E5) шалгана.
- **Утас AI-гаар авсан ч чимээгүй** — `mmsys.cpl`-ийн тохиргоо (E3), `8`-аар дуудлагын төхөөрөмж,
  `7`-оор шалгалт.
- **AI өөрөө өөртэйгөө ярина** — «CABLE Input» Default болсон эсэх (болохгүй), `9`-өөр хэмжээд
  `echo_gate`.
- Тэмдэглэл (log): `%LOCALAPPDATA%\BtoCall\bridge.log` (дугаар, хугацаа, алдааны код л бий;
  залгагчийн дугаар, ярианы үг хэзээ ч бичигдэхгүй).
